## 采样与误差口径

共归档 101 个配对请求与回包，其中可解码并对应选定时间戳的 RGB 有 101 份，匹配的原始深度有 101 份。16 轮的请求、回包、帧、停稳标志和时间窗全部吻合。所记录的选帧至回包耗时为 0.54 至 4.74 个仿真秒。15 轮的最后请求、最后成功回包、等待状态与到达状态逐一匹配。末次原审核表面误差最大 0.048 米；用独立的 20 个静止地面样本对齐，复算的末次表面误差最大 0.042 米。原基准和独立基准分别有 15 和 15 轮落在原 0.20 米限值内。

世界相机高度覆盖 1.73 至 2.29 米。相机高度绝对误差 P95 为 0.219 米，同刻机体里程计误差 P95 为 0.218 米。逐帧扣除机体残差后 P95 为 0.0010 米，成功配准 300 帧。运动帧的取图到 Gazebo 真值查询结束时差为 0.012 至 0.052 仿真秒。

## 判定与适用范围

每轮至少 10 帧。对延迟查询同一拍摄时刻的历史 TF，容许矩阵最大差须小于 1e-8。对各帧已记录的杆表面像素径向误差 P95 重新聚合，Gazebo 相机深度表面的最坏帧上限 0.05 米，地图表面跨帧 P95 上限 0.30 米。重算与运动记录器原报告一致 16/16 轮。运动程序每轮最多取 20 帧，仅统计达到速度、高度、红杆像素和同步条件的视角。表中航向取自能看到目标的实际运动帧。1.5 米仅安排正前和左右 45°，两档均未独立控制横滚和俯仰角。[原 U03 验收标准](../../../../reviews/ubuntu_tasks_2026-10-29.txt)
