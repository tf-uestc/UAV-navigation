# 停稳后等待首个合格的同步相机帧

V03-1.5-right45-2 在第 7 个请求提前结束。原始记录显示停稳已确认，采集时间下限是 51.236 s，检测节点当时缓存的 RGB-D 三元组时间戳是 51.220 s，早了 16 ms。冻结版本直接终止该请求，未调用云端模型。旁路 RGB 留有 51.316 s 和 51.416 s 图像；单独的 RGB 图像无法证明同次深度和内参均到达检测节点。[失败请求与轨迹原文件哈希](incident.json)

候选修改在有采集下限、已启用 RGB/深度/相机内参同步的请求中等待新三元组。三个传感器消息由 TimeSynchronizer 交齐后唤醒工作线程；拿到合格时间戳后照常验证帧龄、图像尺寸、内参、坐标系与历史 TF。等待使用墙钟，默认 1.0 s，并受当前请求的结果时限约束。若超时，终态为 `FAILED/post_stop_frame_timeout`，携带原任务和请求 ID，捕获时刻为 0。当前任务的停稳门槛、外层请求超时、历史结果关联保持原有逻辑。[候选差异与针对性测试](post-stop-frame.patch)
