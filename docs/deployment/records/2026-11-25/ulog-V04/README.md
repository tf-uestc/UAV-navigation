## 失败与适用范围

V03 的 1.5 米右 45° 两轮，首个请求均早于航向就绪，首次请求后分别发生 −10.09° 和 +14.44° 的 NED 航向修正。其余 4 轮近距也在首次请求后重置。2.4 米右 90° 第 2 轮在首次请求前已报告有效，但当时只稳定了 0.860 秒。按首请求前有效统计为 10/16，按逐请求至少 1 秒稳定且无请求后重置统计为 9/16。

- **V04-2.4-right90-1**　未通过10 秒悬停真值。空中首次重置在 19.132 秒（TAKEOFF），NED 航向由 90.74° 至 90.71°，PX4 记录修正 -0.03°。无请求后重置。悬停覆盖 10.348 秒，世界位移 0.151 米，最大停距偏差 0.210 米。任务终态为 `DONE / observation_standoff_reached`。
- **V04-1.5-front-1**　未通过任务完成、终点停距、终点观测、运动定位、10 秒悬停真值。空中首次重置在 18.060 秒（TAKEOFF），NED 航向由 90.87° 至 90.71°，PX4 记录修正 -0.17°。无请求后重置。任务终态为 `FAILED / target_not_found`。6 次检测中 5 次返回未找到，未进入平移段。

同一停距与右 45° 初始方位下，V03 两轮运动地图水平误差 P95 为 0.517、0.511 米，V04 分别为 0.053、0.067 米。

V04 共复核 101 个视觉请求，其中 101 个结果提供可核验的图像时间戳，101 个图像时刻满足机载航向条件。请求前实测最短连续稳定时间为 2.184 个仿真秒。采样来自 PX4 自身的 vehicle_local_position。任务记录用于定位请求和图像的时刻，Gazebo 场景真值仅用于原运动定位指标。此处逐请求的独立复核能验证拍摄时是否满足条件。运行时桥节点发布的每一条 ROS 消息未单独录包。
