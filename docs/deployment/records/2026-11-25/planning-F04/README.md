## 两个需要区分的失败原因

**长程第二轮。** 第五段接近终点时，观察器连续 0.539381 秒未收到新里程计，PX4 目标回传间隔达到 0.599157 秒，超过当时的 0.5 秒里程计墙钟门限。同窗口内执行器状态和任务 ACK 的最大间隔分别仅为 0.100485、0.139273 秒。失败前的实际跟踪轨迹为 16，撤销后迟到的停车样条 17 被拒绝。最近终点样本速度仍为 0.360 米/秒，该轮以 `flight_feedback_unavailable` 中止，随后安全降落。原日志未保存执行器每个保护条件触发时的内部年龄，无法只据此确定宿主调度、Gazebo 或 MAVROS 哪一环节首先迟滞。保留原来失败的分母和门限。[三轮原始时间线与对照](feedback/README.md) · [逐轮摘要及原始文件指纹](feedback/evidence.json)

**未知区恢复轮。** 视野外目标仅观察一次便因 `unknown_trajectory` 退出，全程没有 TRACK。已知空闲目标到达，已占据目标被拒，暂停相机期间平移规划请求为零；恢复输入后，旧授权未重新出现。新任务 `fresh_after_recovery-6d013d53` 实际执行 (1,6)、(1,7)，终点误差 0.181 米、速度 0.048 米/秒。观察器在单调墙钟 7329809.786911 秒记录 `DONE / destination_reached`，14.193 毫秒后才记录试验驱动的 LAND。随后最后一条任务状态为 LANDED。DONE 之后没有再次 TRACK 或提交平移规划，两次独立飞后读数均为已连接、着地、已上锁。[完整状态顺序、命令和时间](initial-23.json)
