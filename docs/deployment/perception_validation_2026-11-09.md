# 2026年11月9日 第10项检测与定位验收

阿里云百炼使用 qwen3.8-omni-flash。请求仅输出文本 JSON，坐标协议明确要求 x、y 按图像宽高归一化到0至1000。模型通过 VLM_MODEL 配置，检测进程读取 VLM_API_KEY 环境变量。服务器项目根目录的 .env 权限为600，Git忽略该文件。配置示例只含占位符。

新增独立检测入口 perception_verified.launch。它以同一采集时间戳配对 RGB、深度和 CameraInfo，在请求之前捕获相机到 map 的历史 TF。返回后按墙钟和 ROS 时间拒绝超龄结果。目标框内用有足够支持的最近深度带估计三维位置，处理镂空目标中较远的背景和零散近处噪点。沿用任务和请求标识校验，以及目标估计器对异常跳变的门控。

| 验证 | 结果 |
| --- | --- |
| 现有离线回归 | 82项通过，含任务标识、目标跳变、深度单位、历史TF |
| 独立ROS回放 | 13项通过，含实拍样本与保存响应、两组姿态和距离、背景与离群深度、无目标、错误单位、无效深度、网络和超时、旧结果、历史TF、错帧 |

真实请求共3次。6毫米量级指当前样本对仿真立杆的水平表面误差。不同距离和姿态的几何对照来自合成回放，实际运动时的感知效果属于后续闭环验收。退出检测节点后，MAVROS仍连接且飞机未解锁。

运行前在服务器项目根目录执行 \`source .env\`，依次加载 ROS Noetic 和业务安装环境，再用 \`roslaunch uav_vln_bringup perception_verified.launch\` 启动独立检测。验证脚本为 \`tools/deployment/validate_perception.py\`。回放使用 master 11316，带 \`--fixture --sample --response --out\`。静态仿真验证使用 master 11311，带 \`--live --out\`，会发出两次模型请求。
