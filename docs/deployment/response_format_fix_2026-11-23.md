## 本次修改

模型曾返回合法单目标 `found:true + label + bbox_2d`，原适配只允许恰好包含label和bbox_2d，因多了found字段而拒绝。现在统一解析以下明确格式：

- 标准对象：found、bbox、coordinate_system。正样本仍要求明确单位。
- 当前固定模型原生对象：label配合bbox_2d或bbox；允许可选的布尔found和一致的coordinate_system，也允许单对象数组或完整JSON代码围栏。
- 未找到：found为false；在明确启用当前模型原生协议时，空数组也作为没有检测结果处理。

原生协议仅适用于已固定的qwen3.8-omni-flash，按请求中明确约定的0至1000坐标换算，不依据数值大小猜单位。默认仍拒绝裸坐标、多目标、反向或越界框、非有限数字、单位冲突、重复JSON键，以及“found为false但同时给出有效框”的矛盾回复。格式异常保持invalid_bbox_response，不伪装为target_not_found。

API回复被长度限制截断时记为invalid_api_response，并沿用当前视角一次重试的既有策略。输出长度上限由128改为256。请求生成代码已用AST对照检查，除这个长度上限外未改变请求和目标提示词；没有新增颜色阈值、换模型或修改可见性策略。原生格式以外的旧坐标协议仍需显式开启。

主要代码为ws/src/uav_vln_bringup/scripts/qwen_vl_grounding.py；增加离线测试和ROS回放用例，并新增tools/deployment/validate_response_format.py。云端两份候选及实际安装模块的内容一致。
