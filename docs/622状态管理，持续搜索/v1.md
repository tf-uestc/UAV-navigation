# UAV 持续搜索与 VLM 迭代修正 — 实施方案

## 一、现状分析

### 1.1 当前项目架构（UAV-navigation-main）

```
UAV-navigation-main/ws/src/uav_vln_bringup/
├── scripts/
│   ├── detector_node.py         # VLM 检测节点（单次调用）
│   ├── planner_node.py          # 规划器加载节点
│   ├── setpoint_bridge.py       # PX4 飞控状态机（IDLE→TAKEOFF→FLYING→LAND）
│   ├── trajectory_follower.py   # 轨迹插值（30Hz）
│   ├── qwen_vl_grounding.py     # VLM 实现（DashScope API）
│   ├── planning/
│   │   ├── ego_adapter.py       # EGO-Planner 桥接
│   │   └── dummy_planner.py     # 测试规划器
│   └── detection/
│       └── base_detector.py     # 检测器基类
├── launch/                      # 8 个 launch 文件
└── simulation/                  # PX4 Gazebo 仿真环境
```

### 1.2 当前数据流

```
/uav/instruction (目标文本)
    → detector_node (调用 VLM 一次)
        → 解析 bbox → 深度融合 → /uav/target_world (3D 坐标)
            → planner_node → ego_adapter → /planning/bspline
                → trajectory_follower (30Hz) → setpoint_bridge (20Hz) → MAVROS
```

### 1.3 核心缺陷

| 缺陷 | 位置 | 影响 |
|------|------|------|
| **VLM 只调一次** | `detector_node.py: _run_detection()` | API 失败 = 任务失败 |
| **无重试逻辑** | `qwen_vl_grounding.py: detect()` 返回 None 即结束 | 无容错 |
| **无搜索模式** | 整个项目无主动探索逻辑 | 无人机被动等待指令 |
| **无任务状态管理** | `setpoint_bridge.py` 只有底层飞控状态 | 无高级任务状态机 |
| **无持续修正** | 飞行途中不再调用 VLM | 初始检测不准则全程偏移 |

## 二、参考项目关键借鉴

### 2.1 OnFly 论文 — 双 Agent 解耦架构

- **Decision Agent（高频）**：每帧预测 2D 航点，驱动飞行
- **Monitoring Agent（低频）**：周期性判断任务状态 {CONTINUE, STOP, LOST}
- **关键启发**：将「飞行控制」与「VLM 检测判断」解耦到不同频率

### 2.2 VLN-Game — 前沿探索 + 懒惰 VLM 调用

- **前沿检测**：系统性覆盖未探索区域
- **懒惰 VLM**：不是每帧调用，而是每隔 N 步且有新候选目标时才调用
- **博弈论排序**：多次 VLM 采样 + 生成器-判别器均衡搜索消除歧义
- **关键启发**：空间索引 + 稀疏 VLM 调用 + 候选目标管理

### 2.3 Ego-Planner — 接口摘要

| 接口 | 话题/方式 |
|------|----------|
| **发送目标** | Publish `nav_msgs/Path` → `/waypoint_generator/waypoints` |
| **接收轨迹** | Subscribe `/planning/bspline`（ego_planner/Bspline）|
| **里程计输入** | `/odom_world`（nav_msgs/Odometry）|
| **碰撞检测** | 内置 50Hz 安全检测，自动重规划或急停 |
| **到达判断** | FSM 轨迹执行完毕 → 回到 WAIT_TARGET |

### 3.1 状态机总览（ASCII 图）

    └──────────┘                  └──────┬───────┘                   │
                                        │                            │
                              VLM 检测到目标                   目标丢失且
                              (confidence > θ₁)              连续丢失 > N 次
                                        │                            │
                                        ▼                            │
                                ┌───────────────┐                    │
                         ┌─────│   DETECTED     │                    │
                         │     └───────┬────────┘                    │
                         │             │                             │
                    置信度不够      置信度 > θ₂                      │
                    或需要确认      (确认目标)                        │
                         │             │                             │
                         ▼             ▼                             │
                  ┌────────────┐  ┌──────────────┐                   │
                  │ VERIFYING  │  │  APPROACHING  │──────────────────┘
                  └─────┬──────┘  └──────┬────────┘   (飞近后 VLM 找不到)
                        │                │
                   确认成功           到达目标附近
                   (→ APPROACHING)    (距离 < d_thresh)
                        │                │
                        │                ▼
                        │         ┌──────────────┐
                        └────────→│  COMPLETED   │
                                  └──────────────┘

                    任意状态 ──电量低/紧急──→  [EMERGENCY_RTL]
```

### 3.2 状态定义

| 状态 | 说明 | VLM 调用策略 | Ego-Planner 行为 |
|------|------|-------------|------------------|
| **IDLE** | 等待任务指令 | 不调用 | 悬停 |
| **SEARCHING** | 执行搜索模式（弓字/螺旋） | 每 T₁ 秒调用一次（默认 3s） | 跟踪搜索航点 |
| **DETECTED** | 首次检测到候选目标 | 立即再调一次确认 | 减速/悬停 |
| **VERIFYING** | 多角度/多次 VLM 确认 | 连续调用 K 次（默认 3） | 悬停或微调姿态 |
| **APPROACHING** | 飞向已确认目标 | 每 T₂ 秒调用修正（默认 5s） | 跟踪更新后的目标点 |
| **COMPLETED** | 到达目标附近 | 最终一次确认 | 悬停 |
| **EMERGENCY_RTL** | 紧急返航 | 不调用 | 返航点 |

# ws/src/uav_vln_bringup/scripts/mission/state_machine.py

import rospy
from enum import Enum, auto

class MissionState(Enum):
    IDLE = auto()
    SEARCHING = auto()
    DETECTED = auto()
    VERIFYING = auto()
    APPROACHING = auto()
    COMPLETED = auto()
    EMERGENCY_RTL = auto()

class MissionStateMachine:
    def __init__(self):
        self.state = MissionState.IDLE
        self.target_text = ""
        self.target_position = None
        self.confidence = 0.0
        self.detection_count = 0        # 连续检测成功计数
        self.miss_count = 0             # 连续检测失败计数
        self.verify_results = []        # 验证阶段的检测结果列表

        # 可配参数
        self.CONFIDENCE_DETECT = rospy.get_param("~confidence_detect", 0.5)
        self.CONFIDENCE_CONFIRM = rospy.get_param("~confidence_confirm", 0.7)
        self.MAX_MISS_BEFORE_RESEARCH = rospy.get_param("~max_miss", 5)
        self.VERIFY_COUNT = rospy.get_param("~verify_count", 3)
        self.APPROACH_DISTANCE = rospy.get_param("~approach_distance", 2.0)
        self.SEARCH_VLM_INTERVAL = rospy.get_param("~search_vlm_interval", 3.0)
        self.APPROACH_VLM_INTERVAL = rospy.get_param("~approach_vlm_interval", 5.0)

    def transition(self, event, data=None):
        """统一的状态转移函数"""
        old = self.state

        if self.state == MissionState.IDLE:
            if event == "START_MISSION":
                self.target_text = data["target_text"]
                self.state = MissionState.SEARCHING

        elif self.state == MissionState.SEARCHING:
            if event == "TARGET_DETECTED":
                if data["confidence"] >= self.CONFIDENCE_DETECT:
                    self.target_position = data["position"]
                    self.confidence = data["confidence"]
                    self.state = MissionState.DETECTED

        elif self.state == MissionState.DETECTED:
            if event == "CONFIDENCE_HIGH":
                self.state = MissionState.APPROACHING
            elif event == "NEED_VERIFY":
                self.verify_results = []
                self.state = MissionState.VERIFYING

        elif self.state == MissionState.VERIFYING:
            if event == "VERIFY_RESULT":
                self.verify_results.append(data)
                if len(self.verify_results) >= self.VERIFY_COUNT:
                    avg_conf = sum(r["confidence"] for r in self.verify_results) / len(self.verify_results)
                    if avg_conf >= self.CONFIDENCE_CONFIRM:
                        self._fuse_positions()
                        self.state = MissionState.APPROACHING
                    else:
                        self.state = MissionState.SEARCHING

        elif self.state == MissionState.APPROACHING:
            if event == "TARGET_REACHED":
                self.state = MissionState.COMPLETED
            elif event == "TARGET_LOST":
                self.miss_count += 1
                if self.miss_count > self.MAX_MISS_BEFORE_RESEARCH:
                    self.miss_count = 0
                    self.state = MissionState.SEARCHING
            elif event == "TARGET_UPDATED":
                self.target_position = data["position"]
                self.confidence = data["confidence"]
                self.miss_count = 0

        if event == "EMERGENCY":
            self.state = MissionState.EMERGENCY_RTL

        if old != self.state:
            rospy.loginfo(f"[Mission] {old.name} -> {self.state.name}")

    def _fuse_positions(self):
        """融合多次检测的位置（加权平均）"""
        total_w = sum(r["confidence"] for r in self.verify_results)
        fused = [0, 0, 0]
        for r in self.verify_results:
            w = r["confidence"] / total_w
            for i in range(3):
                fused[i] += r["position"][i] * w
        self.target_position = fused
```

### 4.2 SearchPatternGenerator（搜索模式生成器）

```python
# ws/src/uav_vln_bringup/scripts/mission/search_patterns.py

import math
import numpy as np

class SearchPatternGenerator:
    """生成各种搜索航点序列"""

    @staticmethod
    def expanding_square(center, start_size=5.0, step=3.0, altitude=8.0, max_rings=5):
        """扩展方形搜索（从中心向外扩展）"""
        waypoints = []
        for ring in range(1, max_rings + 1):
            half = start_size + step * ring
            corners = [
                (center[0] - half, center[1] - half),
                (center[0] + half, center[1] - half),
                (center[0] + half, center[1] + half),
                (center[0] - half, center[1] + half),
            ]
            for cx, cy in corners:
                waypoints.append((cx, cy, altitude))
        return waypoints

    @staticmethod
    def lawnmower(center, width=30.0, height=30.0, spacing=5.0, altitude=8.0):
        """弓字形搜索（系统性覆盖矩形区域）"""
        waypoints = []
        x_start = center[0] - width / 2
        y_start = center[1] - height / 2
        num_passes = int(width / spacing) + 1
        for i in range(num_passes):
            x = x_start + i * spacing
            if i % 2 == 0:
                waypoints.append((x, y_start, altitude))
                waypoints.append((x, y_start + height, altitude))
            else:
                waypoints.append((x, y_start + height, altitude))
                waypoints.append((x, y_start, altitude))
        return waypoints

    @staticmethod
    def spiral(center, max_radius=20.0, spacing=3.0, altitude=8.0, points_per_ring=12):
        """螺旋搜索（从中心向外螺旋）"""
        waypoints = []
        total_points = int(max_radius / spacing) * points_per_ring
        for i in range(total_points):
            angle = 2 * math.pi * i / points_per_ring
            radius = spacing * i / points_per_ring
            if radius > max_radius:
                break
            x = center[0] + radius * math.cos(angle)
            y = center[1] + radius * math.sin(angle)
            waypoints.append((x, y, altitude))
        return waypoints
```

### 4.3 TargetTracker（目标跟踪与置信度管理）

```python
# ws/src/uav_vln_bringup/scripts/mission/target_tracker.py

import time
import numpy as np

class TargetTracker:
    """
    管理候选目标，融合多次 VLM 检测结果。
    借鉴 VLN-Game 的候选管理 + OnFly 的时序融合。
    """
    def __init__(self, decay_rate=0.95, merge_distance=3.0):
        self.candidates = []        # [{position, confidence, last_seen, hit_count}]
        self.best_target = None
        self.decay_rate = decay_rate
        self.merge_distance = merge_distance

    def update(self, detection):
        """接收一次 VLM 检测结果并更新候选列表"""
        if detection is None:
            self._decay_all()
            return

        pos = np.array(detection["position"])
        merged = False

        for cand in self.candidates:
            dist = np.linalg.norm(pos - np.array(cand["position"]))
            if dist < self.merge_distance:
                # 加权融合位置
                w_new = detection["confidence"]
                w_old = cand["confidence"]
                total = w_new + w_old
                cand["position"] = (
                    (np.array(cand["position"]) * w_old + pos * w_new) / total
                ).tolist()
                cand["confidence"] = min(1.0, (w_old + w_new) * 0.6)
                cand["last_seen"] = time.time()
                cand["hit_count"] += 1
                merged = True
                break

        if not merged:
            self.candidates.append({
                "position": pos.tolist(),
                "confidence": detection["confidence"],
                "last_seen": time.time(),
                "hit_count": 1
            })

        self._update_best()

    def _decay_all(self):
        """未检测到时衰减所有候选"""
        for cand in self.candidates:
            cand["confidence"] *= self.decay_rate
        self.candidates = [c for c in self.candidates if c["confidence"] > 0.1]
        self._update_best()

    def _update_best(self):
        if self.candidates:
            self.best_target = max(self.candidates, key=lambda c: c["confidence"])
        else:
            self.best_target = None
```

### 4.4 MissionManagerNode（主节点）

```python
# ws/src/uav_vln_bringup/scripts/mission/mission_manager_node.py

#!/usr/bin/env python3
import rospy
import json
import numpy as np
from std_msgs.msg import String
from geometry_msgs.msg import PoseStamped
from nav_msgs.msg import Odometry
from std_srvs.srv import Trigger, TriggerResponse

from state_machine import MissionStateMachine, MissionState
from search_patterns import SearchPatternGenerator
from target_tracker import TargetTracker


class MissionManagerNode:
    def __init__(self):
        rospy.init_node("mission_manager")

        self.fsm = MissionStateMachine()
        self.tracker = TargetTracker()
        self.search_gen = SearchPatternGenerator()

        self.current_pos = None
        self.search_waypoints = []
        self.search_idx = 0
        self.last_vlm_time = 0

        # Publishers
        self.target_pub = rospy.Publisher("/uav/target_world", PoseStamped, queue_size=1)
        self.state_pub = rospy.Publisher("/mission/state", String, queue_size=1)
        self.detection_req_pub = rospy.Publisher("/uav/detection_request", String, queue_size=1)

        # Subscribers
        rospy.Subscriber("/uav/detection_result", String, self._on_detection)
        rospy.Subscriber("/mavros/local_position/odom", Odometry, self._on_odom)
        rospy.Subscriber("/mission/command", String, self._on_command)

        # Services
        rospy.Service("/mission/abort", Trigger, self._handle_abort)

        # Main loop timer
        self.timer = rospy.Timer(rospy.Duration(0.1), self._tick)  # 10 Hz

        rospy.loginfo("[MissionManager] Initialized")

    def _on_odom(self, msg):
        p = msg.pose.pose.position
        self.current_pos = [p.x, p.y, p.z]

    def _on_command(self, msg):
        cmd = json.loads(msg.data)
        if cmd.get("action") == "search":
            self.fsm.transition("START_MISSION", {"target_text": cmd["target_text"]})
            self._init_search(cmd.get("search_center"), cmd.get("pattern", "expanding_square"))

    def _on_detection(self, msg):
        result = json.loads(msg.data)
        detection = None
        if result.get("success"):
            detection = {
                "position": result["world_position"],
                "confidence": result["confidence"],
                "bbox": result.get("bbox"),
            }

        self.tracker.update(detection)
        state = self.fsm.state

        if detection:
            if state == MissionState.SEARCHING:
                self.fsm.transition("TARGET_DETECTED", detection)
                if self.fsm.state == MissionState.DETECTED:
                    if detection["confidence"] >= self.fsm.CONFIDENCE_CONFIRM:
                        self.fsm.transition("CONFIDENCE_HIGH")
                    else:
                        self.fsm.transition("NEED_VERIFY")
            elif state == MissionState.VERIFYING:
                self.fsm.transition("VERIFY_RESULT", detection)
            elif state == MissionState.APPROACHING:
                self.fsm.transition("TARGET_UPDATED", detection)
        else:
            if state == MissionState.APPROACHING:
                self.fsm.transition("TARGET_LOST")

    def _tick(self, event):
        """10Hz 主循环"""
        state = self.fsm.state
        now = rospy.get_time()

        if state == MissionState.SEARCHING:
            self._execute_search()
            if now - self.last_vlm_time >= self.fsm.SEARCH_VLM_INTERVAL:
                self._request_detection()
                self.last_vlm_time = now

        elif state == MissionState.VERIFYING:
            if now - self.last_vlm_time >= 1.0:
                self._request_detection()
                self.last_vlm_time = now

        elif state == MissionState.APPROACHING:
            self._execute_approach()
            if now - self.last_vlm_time >= self.fsm.APPROACH_VLM_INTERVAL:
                self._request_detection()
                self.last_vlm_time = now
            self._check_arrival()

        elif state == MissionState.EMERGENCY_RTL:
            self._publish_target([0, 0, 5])  # 返航点

        self._publish_state()

    def _init_search(self, center=None, pattern="expanding_square"):
        if center is None:
            center = self.current_pos[:2] if self.current_pos else [0, 0]
        gen = getattr(self.search_gen, pattern, self.search_gen.expanding_square)
        self.search_waypoints = gen(center)
        self.search_idx = 0

    def _execute_search(self):
        if not self.search_waypoints or self.current_pos is None:
            return
        wp = self.search_waypoints[self.search_idx]
        dist = np.linalg.norm(np.array(self.current_pos) - np.array(wp))
        if dist < 2.0:
            self.search_idx = (self.search_idx + 1) % len(self.search_waypoints)
            wp = self.search_waypoints[self.search_idx]
        self._publish_target(wp)

    def _execute_approach(self):
        if self.tracker.best_target:
            self._publish_target(self.tracker.best_target["position"])

    def _check_arrival(self):
        if self.current_pos and self.tracker.best_target:
            dist = np.linalg.norm(
                np.array(self.current_pos) - np.array(self.tracker.best_target["position"])
            )
            if dist < self.fsm.APPROACH_DISTANCE:
                self.fsm.transition("TARGET_REACHED")

    def _request_detection(self):
        msg = String()
        msg.data = json.dumps({"target_text": self.fsm.target_text})
        self.detection_req_pub.publish(msg)

    def _publish_target(self, pos):
        msg = PoseStamped()
        msg.header.stamp = rospy.Time.now()
        msg.header.frame_id = "map"
        msg.pose.position.x = pos[0]
        msg.pose.position.y = pos[1]
        msg.pose.position.z = pos[2] if len(pos) > 2 else 8.0
        self.target_pub.publish(msg)

    def _publish_state(self):
        state_info = {
            "state": self.fsm.state.name,
            "target_text": self.fsm.target_text,
            "confidence": self.fsm.confidence,
            "target_position": self.fsm.target_position,
            "candidates": len(self.tracker.candidates),
        }
        self.state_pub.publish(String(data=json.dumps(state_info)))

    def _handle_abort(self, req):
        self.fsm.transition("EMERGENCY")
        return TriggerResponse(success=True, message="Mission aborted")


if __name__ == "__main__":
    try:
        MissionManagerNode()
        rospy.spin()
    except rospy.ROSInterruptException:
        pass
```

### 4.5 detector_node.py 改造方案

当前 `detector_node.py` 是一次性调用，需要改造为**请求-响应模式**：

```python
# 在现有 detector_node.py 中增加以下改动:

# 1. 新增订阅: 接收检测请求
rospy.Subscriber("/uav/detection_request", String, self._on_detection_request)

# 2. 新增发布: 发送检测结果
self.result_pub = rospy.Publisher("/uav/detection_result", String, queue_size=1)

def _on_detection_request(self, msg):
    """响应检测请求，执行一次 VLM 检测并发布结果"""
    req = json.loads(msg.data)
    target_text = req["target_text"]

    # 复用现有的 _run_detection 逻辑，但不再一次性
    detection = self.detector.detect(rgb, depth, target_text, cam_info)

    result = {"success": False}
    if detection is not None:
        world_pos = self._transform_to_map(detection)
        result = {
            "success": True,
            "world_position": [world_pos.x, world_pos.y, world_pos.z],
            "confidence": detection.confidence,
            "bbox": detection.bbox,
        }

    self.result_pub.publish(String(data=json.dumps(result)))
```

## 五、搜索策略设计

### 5.1 自适应搜索策略

```
初始搜索 (SEARCHING):
├── 默认: expanding_square (扩展方形, 从当前位置外扩)
├── 若有先验区域: lawnmower (弓字形, 覆盖指定区域)
└── 若首次检测后丢失: spiral (螺旋, 从最后已知位置出发)

逼近搜索 (APPROACHING 中丢失目标后):
├── 以最后已知位置为中心
├── 使用 spiral 模式, 半径较小 (10m)
└── 若仍未找到, 升高高度重新大范围搜索
```

### 5.2 VLM 调用时机（借鉴 VLN-Game 的懒惰调用）

| 状态 | 调用间隔 | 触发条件 | 理由 |
|------|---------|---------|------|
| SEARCHING | 3s | 到达新航点 or 定时 | 覆盖不同视角 |
| DETECTED | 立即 | 状态进入时 | 快速确认 |
| VERIFYING | 1s | 连续 3 次 | 多次采样消除随机性 |
| APPROACHING | 5s | 定时 + 距离变化 > 3m | 持续修正但避免过度调用 |
| COMPLETED | 一次 | 最终确认 | 确保到位 |

### 5.3 失败恢复策略

```
VLM API 调用失败:
├── 网络超时 → 指数退避重试 (2s, 4s, 8s), 最多 3 次
├── 返回 None (未检测到) → 正常流程, 由状态机计数处理
└── 连续 10 次 API 失败 → 切换到 GPS/惯导模式继续飞行, 等待 API 恢复

目标丢失 (APPROACHING 中):
├── miss_count < 3 → 保持当前航向, 继续飞
├── 3 ≤ miss_count < 5 → 降速, 缩短 VLM 间隔到 2s
└── miss_count ≥ 5 → 回退到 SEARCHING, 以最后位置为中心螺旋搜索
```

## 八、关键设计决策说明

| 决策 | 选择 | 理由 |
|------|------|------|
| 状态机实现 | 自定义 Python 类 | 比 SMACH 轻量，比 BehaviorTree 简单，适配现有纯 Python 架构 |
| VLM 调用方式 | 请求-响应（Pub/Sub）| 解耦检测与决策，支持异步，不阻塞主循环 |
| 目标融合 | 加权平均 + 置信度衰减 | 借鉴 VLN-Game 的候选管理，简单有效 |
| 搜索模式 | 参数化生成器 | 可配置、可切换，适应不同场景 |
| 频率解耦 | 主循环 10Hz, VLM 0.2-1Hz | 借鉴 OnFly 的高低频解耦思想 |
